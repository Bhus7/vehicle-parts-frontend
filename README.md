# Vehicle Parts Management Frontend

This is the frontend component of the Vehicle Parts Management application. It is built using React, TypeScript, Vite, Tailwind CSS, and Material-UI.

## Getting Started

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm or yarn

### Installation

Install the dependencies from the root directory:

```bash
npm install
```

### Running the Development Server

Start the development server:

```bash
npm run dev
```

The application will run locally (typically at `http://localhost:5173/`).

### Building for Production

To build the application for production:

```bash
npm run build
```

The production assets will be generated in the `dist` directory.
